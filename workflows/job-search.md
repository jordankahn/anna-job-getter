# Workflow: Aggressive Niche Job Search

Goal: surface specialized arts/nonprofit/arts-education listings beyond the
generic LinkedIn/Indeed feed, filtered to Anna's hard requirements.

## Hard filters
- Salary ≥ $50,000/year (listed preferred and prioritized).
- Chicagoland onsite/hybrid OR fully remote (US/IL-eligible).
- Full-time.

## Search method
1. Work the niche boards in `sources/niche-job-sources.md` first — these surface
   roles that never reach LinkedIn/Indeed.
2. Search target org career pages directly (theaters, museums, symphony,
   community music schools, JCCs, foundations, universities' arts/ed depts,
   park-district cultural programs).
3. Use varied role queries (arts administrator, program coordinator/manager,
   operations coordinator, development/donor coordinator, education programs
   associate/coordinator/manager, community engagement coordinator, membership
   coordinator, teaching-artist program manager).
4. Verify each hit by opening the real posting; never include a listing without a
   real URL. Capture salary, location, posted date, and cover-letter requirement.

## Output
Write `search-results/YYYY-MM-DD-search.md` with, per listing:
- Title — Org (location / remote), direct URL, salary, posted date,
  why it fits (2–3 sentences), source board, **A–F fit grade**, cover-letter req.
- Sort by grade. Flag any that fail a filter but are close.
- End with the most productive boards and standing pre-filtered search URLs to
  bookmark.

## Hand-off
For any A/B listing the user picks, run `workflows/process-listing.md`.
