# Resume Tailoring Guide — Anna Brown (Aggressive but Legitimate ATS)

Goal: rank at the top of the ATS **and** read well to a human, without any
deceptive tricks. We win by genuinely matching the posting's language to Anna's
real experience.

## ATS rules (format)
- **Single column, no tables, no text boxes, no headers/footers** for core
  content. Multi-column and table layouts break many parsers (Workday, iCIMS,
  Taleo). Anna's current PDFs use a two-column layout — for ATS submissions,
  use the single-column base here.
- Standard section headings exactly: **Summary, Skills, Experience, Education,
  Awards**. Parsers look for these literal words.
- Standard fonts (Calibri/Arial/Garamond), 10.5–12pt, black text.
- Real bullet characters (•), no graphics/icons. Dates right-aligned as plain text
  "Mon YYYY – Mon YYYY".
- Save/submit as **.docx or text-based .pdf** (never image/scanned).
- Name file `Anna_Brown_Resume_<Org>_<Role>.pdf`.
- **No hidden white-text keyword stuffing.** Modern ATS read raw text and expose
  it; screeners flag it. We do not use it.

## Keyword mirroring (the legitimate edge)
1. Extract the posting's **hard requirements, repeated nouns, tools, and the
   exact job title.** Build a keyword list.
2. For each keyword, find Anna's **true** matching experience and use the
   posting's wording (e.g., posting says "stakeholder communication" → reframe
   her "community-partner communication" as "stakeholder communication").
3. Put the **exact target job title** in the summary line when truthful
   ("Arts administrator and program coordinator…").
4. Surface matched **tools by name** (Salesforce, Eventive, Stampli, Google
   Workspace) in the Skills section so exact-match parsers catch them.
5. Reorder Experience bullets so the most relevant-to-this-posting come first.
6. Aim for strong keyword coverage of the must-haves; never claim a skill Anna
   lacks. If a must-have is missing, get as close as her real adjacent
   experience honestly allows and flag the gap in the evaluation.

## Bullet formula
`Strong verb + what you did + tool/scope + outcome/number.`
Use Anna's real numbers (16 counselors, 80+ campers, annual film festival).
Vary verbs: Coordinated, Managed, Produced, Built, Led, Developed, Processed,
Tracked, Supported, Designed. (Avoid "spearheaded.")

## Two base versions
- **Track A (arts admin / nonprofit):** lead with JCC Operations Coordinator +
  Film Festival, nonprofit operations, invoicing/CRM, events, community
  engagement. Education roles compressed below.
- **Track B (arts / music education):** lead with teaching, curriculum, youth
  programming, music direction. Operations supports it.

Pick the base that matches the posting, then keyword-tailor it. Keep to one page
unless the posting invites more.

## Per-job output
For each listing, produce `Anna_Brown_Resume_<slug>.md` (and a Google Doc),
plus a short note listing which keywords were mirrored and any honest gaps.
